# 11/19 기사 5편 · 시드 150편 · 관점 지도 적용 안내 (형준용)

> 저장소(fevertime-team/chaekmun)를 이쪽에서 열지 못해서, 기존 `index.html` 데이터 형식에 맞추지 않고 **형식에 묶이지 않는 JSON**으로 만들었습니다. 아래 "옮겨 넣기 지시문"을 저장소를 연 Claude(또는 형준)에게 주면 기존 형식으로 바꿔 넣을 수 있습니다.

## 1. 파일

| 파일 | 내용 |
|---|---|
| `articles_1119.json` | 기사 5편 패키지: 분야, 제목, 언론사(그룹), 발행 시각, 원문 링크, 한 줄·3줄 요약, 쟁점, 초시·복시 질문, 입장 6개, 공통 페르소나 5명 + 전문가 2명, 시관 주의사항(guard_note), **예시 답안(demo_answer)** |
| `seeds_1119.json` | 시드 150편 (기사마다 30편 = 복시 18 + 초시 12). 필드: id, article_id, level(boksi/chosi), group_id, group_name, text, argument(핵심 논거 한 문장), writer, is_representative, is_eoram, source="seed" |
| `perspective_map_1119.json` | 기사별 관점 지도: 6그룹(이름·설명·크기·비율), 그룹 대표 답안 id, 어람작 id, 그룹에 속한 시드 id 목록 |
| `seeds_1119.csv` | 사람이 엑셀로 검토하는 용도 (같은 내용) |
| `seed_data.py` + `build_seeds.py` | 원본과 생성기. 글을 고치면 `python3 build_seeds.py` → JSON 다시 생성 + 규칙 검사 |

## 2. 구조 (5편 모두 같은 모양)

- 그룹 크기: g1 7 · g2 6 · g3 6 · g4 5 · g5 4 · **g6 2 (소수 군집)**
- g1~g5: 그룹마다 복시 대표 답안 1편 (`is_representative: true`)
- g6: 어람작 1편 (`is_eoram: true`) = 작은 군집 + 논리가 탄탄한 글
- 초시 시드도 복시 6그룹에 배정 (지난번 결정대로, 코드 변경 없음)
- 시드는 모두 AI가 쓴 예시 답안(`source: "seed"`). 발표 Q&A 답: "실제 답안 0개 + AI 페르소나 답안 150개, 처음부터 밝힌다"

## 3. 앱 연결 지점

| 화면 | 쓰는 데이터 |
|---|---|
| 기사 고르기 | `articles[].one_line`, category, press |
| 질문 | `summary3`, `chosi`/`boksi`, url, (원문 전문은 팀이 붙여 넣기) |
| 쓰기 → "예시 답안으로 체험하기" | `demo_answer.text` (일부러 빈틈 하나씩 있음 → `weakness`에 적어 둠, 반론이 그걸 짚는지 확인용) |
| 반론 페르소나 | `personas_common` 5명 + `personas_expert` 2명. 지시문에 `guard_note` 덧붙이기 |
| 광장 배정 [API ⑥ assign] | 사용자 답을 `perspective_map.groups[].name/description`과 비교해 가장 가까운 그룹에 배정 |
| 관점 지도 | 그룹 6개, 크기는 `size`, 대표 답안은 `representative_id`의 본문, 어람작은 `eoram_id` |

- 관점 지도를 **실제 임베딩·군집화로 다시 계산**하려면 각 시드의 `argument`(핵심 논거)를 임베딩하면 됩니다. 결과 그룹이 미리 정한 6그룹과 조금 달라도 괜찮지만, 시연 안정성을 위해 **화면은 미리 정한 group_id로 그리는 것**을 권합니다.
- 초시/복시를 따로 보여 줄 거면 `level`로 거르면 됩니다. 그룹은 같습니다.

## 4. 옮겨 넣기 지시문 (저장소를 연 Claude에게 그대로)

```
첨부한 articles_1119.json, seeds_1119.json, perspective_map_1119.json을
index.html 안의 기존 기사·시드·관점 지도 데이터 형식으로 바꿔서 교체해 줘.
- 기존 기사 3편(주 4.5일제, AI 안경, 로보택시) 데이터는 지우고 5편으로 바꾼다.
- 기존 필드 이름을 유지하고, 새 JSON에 있는데 기존 형식에 자리가 없는 필드(guard_note, other_view, date_check, argument)는 버리지 말고 주석이나 새 필드로 남겨 줘.
- 대표 답안·어람작 표시, 그룹 크기, 초시/복시 구분을 그대로 옮겨 줘.
- 바꾼 뒤 npm run data로 server/content.json을 다시 만들고, 화면에서 5편 모두 질문→광장까지 넘어가는지 확인해 줘.
- 바꾼 필드 대응표를 마지막에 보여 줘.
```
