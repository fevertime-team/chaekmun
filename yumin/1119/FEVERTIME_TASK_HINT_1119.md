> 원칙: 요약 몇 번째 줄을 보라고 가리키기만 하고, 답이나 입장은 알려 주지 않습니다. 원문에 없는 사실은 넣지 않았습니다.

## 형준(또는 저장소를 연 Claude)에게 줄 지시문

```
아래 JSON의 힌트를 TASK_HINT에 넣어 줘.
- 바깥 키 "<…기사 id>"는 이번에 넣은 11/19 기사 5편의 실제 기사 id로 바꿔. ARTICLES, SEEDS, TASK_HINT의 id가 모두 같아야 해.
- 안쪽 키(쟁점 설명, 근거 활용, 맥락과 전제, 자기 입장, 결론과 함의)는 tasks.ts의 TASKS가 쓰는 axis 키 이름으로 바꿔 줘. 대응: 쟁점 설명, 근거 활용, 맥락과 전제, 자기 입장, 결론과 함의 순서는 tasks.ts의 5기준 순서와 같아.
- 옛 기사 id(work45, fueltax, aiexam, robotaxi, aidc)의 힌트는 지워.
- 넣은 뒤 5편 모두 쓰기 화면에서 "이 기사에서는" 줄이 비지 않는지 확인해 줘.
```
