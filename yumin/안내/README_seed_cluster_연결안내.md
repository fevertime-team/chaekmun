# 시드 답안과 관점 지도 만들기 — 형준용 (사전 계산, 시연 전 1회)

## ✅ 11/18 밤 업데이트: 1단계와 4단계는 이미 끝났어
- AI 시드 답안 108개(기사별 36개)를 미리 써서 `data/seeds/seeds_{기사}.json`에 넣었고, 관점 지도 묶기까지 끝내서 `articles-v2.ts`의 clusters에 반영했어.
- 그래서 **아래 1단계(시드 생성)와 4단계(묶기)는 건너뛰어도 돼.** API 호출 108번이 줄었어.
- 남은 일: 실사용 테스트 답안이 생기면 2단계(실제 답안 섞기) → 4단계를 다시 한 번 돌리기, 5단계(새 답안 배정 assign) 연결. 3단계(채점으로 logic 교체)는 시간이 남을 때만.

## 왜 필요한가
광장의 관점 지도는 지금 임시 데이터야. 실제 답안들을 Claude로 묶어서 만든 지도를 보여 줘야 "획일화하지 않는 AI"의 근거가 돼.
시드 답안은 **AI 페르소나 답안 + 실제 사람 답안**을 섞고, 발표에서 구성을 그대로 밝힐 거야.

## 1단계: AI 시드 답안 108개 만들기 (`npm run seed:answers` 같은 스크립트)
- `seed_personas.csv`: 기사 3건 × 36명. 칸: id, article, level, stance, stance_label, angle(논거 각도), skill(글 실력 상/중/하), major, tone, source
- 한 줄마다 `seed.txt`로 Claude 1번 호출 → `{"answer": "..."}` → id와 함께 `data/seeds/{article}.json`에 저장
- 모델: **Haiku**로 충분 (108번 호출이라 비용 차이가 큼). 이상하면 Sonnet
- 변수: `{{article_title}}`, `{{article_lines}}`, `{{level_name}}`(복시), `{{question}}`(복시 질문), `{{major}}`, `{{stance_label}}`, `{{angle}}`, `{{skill}}`, `{{tone}}`
- 우선순위: **aiexam(시연 대표 기사) → work45 → robotaxi**. 시간이 없으면 aiexam만

## 2단계: 실제 답안 섞기
- 팀원 3명 + 실사용 테스트 참가자의 복시 답안을 `source: "real"`로 같은 파일에 추가 (이름 대신 "응시자 ○○")
- 개인정보가 들어간 문장은 빼기

## 3단계: 답안마다 논리 점수 매기기
- 시드 답안마다 `score.txt`로 1번 채점 → 4축 평균을 `logic`(예: 3.6)으로 저장
- 어람작(소수의견) 후보를 고를 때 씀

## 4단계: 관점 지도 묶기 (`cluster.txt`)
- 기사별로 1번 호출. `{{answers_with_ids}}`에 `[aiexam-01] 답안 전문` 형식으로 전부
- 모델: **Sonnet** (전체를 한 번에 보고 판단해야 해서)
- 결과를 기존 `clusters` 형식으로 바꿔서 `articles-v2.ts`(또는 DB)에 저장:
  - `label`, `stance` → 그대로
  - `n` = member_ids 개수
  - `s.text` = representative_id 답안 원문, `s.who` = "응시자 " + 번호
  - `logic` = 그룹 구성원 logic 평균
  - `tam`(어람작 후보) = **구성원이 전체의 10% 이하인 그룹 중 logic 평균이 가장 높은 그룹 1개**
  - `agree`, `pen`(투표 수) = 시연용 숫자. 어람작은 agree 낮고 pen 높게
- 위치 `x, y` (지도에서 원의 자리): 입장별로 좌우를 나누고, 어람작은 위쪽 가운데
  - 입장 목록의 첫 번째 입장 → x 0.25~0.35, 두 번째 → x 0.65~0.75, 세 번째·other → x 0.3~0.7 사이 아래쪽(y 0.7~0.8), 어람작 → x 0.5, y 0.14
  - 원끼리 겹치지 않게 y를 0.32~0.78 사이에서 벌리기

## 5단계: 새 사용자 답안을 그룹에 배정 (`assign.txt`, 실시간)
- 광장 제출 때 1번 호출 → `group_label`로 "내 글" 위치 표시
- 모델: Haiku. `{{groups}}`에 `그룹 이름: summary` 목록
- 서버 보정: group_label이 목록에 없으면 같은 입장의 가장 큰 그룹으로
