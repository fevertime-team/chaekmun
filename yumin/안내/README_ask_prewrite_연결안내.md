# 묻기(ask)·쓰기 전 질문(prewrite) 연결 안내 — 형준용

## 1. 시관에게 묻기 (`/api/ask`)
### 흐름
1. **규칙으로 먼저 거르기 (코드, 무료):** 목업의 정규식("고쳐|써 줘|대신|모범|예시 답|정답|첫 문장|한 문장만") + 영어("rewrite|write it|fix it|example")에 걸리면 Claude를 부르지 않고 바로 거절 답 + 피드백의 첫 번째 약점 질문을 돌려줘. (빠르고 비용 0)
2. 규칙에 안 걸리면 `ask.txt`로 Claude 호출 → `{intent, refused, reply}`
3. 화면: refused면 말풍선 왼쪽에 붉은 선 (v2 목업 `.bub.ai.refuse`)

### 변수
| 변수 | 넣는 값 |
|---|---|
| `{{article_title}}`, `{{question}}`, `{{answer_sentences}}` | feedback과 같음 |
| `{{feedback_summary}}` | 숨은 전제(근거 [n] → 주장 [m]), 약점들(유형, 문장 번호, 질문), 반론(누구, 내용, 질문)을 줄글로 |
| `{{chat_history}}` | 최근 4개. `사용자: …` / `시관: …` |
| `{{user_message}}` | 새 질문 |

### 모델
- `ASK_MODEL` (기본 Sonnet. 응답이 느리면 Haiku로)
- 서버 보정: reply가 4문장을 넘으면 앞 3문장만. reply 안에 사용자 답안 문장과 글자 겹침 0.5 이상인 "새 문장"이 있으면 규칙 거절 답으로 대체

## 2. 쓰기 전 생각할 거리 (`/api/prewrite`, 새로 만들기)
- 화면: 쓰기 단계에서 "무엇부터 써야 할지 막막하다면, 생각할 거리 받기" 링크 (v2 목업 참고) → 누르면 질문 3개 표시
- `prewrite.txt` + `prewrite.schema.json`, 모델 Sonnet
- **비용 절약:** 기사 3건 × 초시·복시 = 6가지뿐이라 **미리 한 번씩 만들어 저장**해 두고 꺼내 써도 돼. 시연 때 응답 지연도 없어짐
- 서버 보정: 질문이 3개가 아니면 앞 3개만, 3개 미만이면 미리 저장한 것으로
